## Part 1: Session Opening Mechanics

How each session begins reveals the inter-session architecture more than anything else. The opening is where prior context gets reintroduced, commitments get tracked, and the "thread" between sessions becomes visible.

### Session-by-Session Opening Comparison

| Session | Opening Move | Time Spent | Function |
|---------|-------------|------------|----------|
| **Setup (Dec 17)** | Broad exploration: "What brings you here?" | ~full session | List everything, initial prioritization, explain process |
| **Session 1 (Jan 5)** | Coach reads back 7 items from setup notes, asks for validation | ~15 min | Memory demonstration + shared foundation + re-entry |
| **Session 2 (Jan 12)** | Personal check-in (coach shares car accident), then direct commitment follow-up: "Did you meet with Oseas?" | ~13 min (10 check-in + 3 follow-up) | Emotional calibration + accountability |
| **Session 3 (Jan 19)** | Brief check-in, curiosity about commitments, explicit time framing ("we have this session and one more") | ~8 min | Light follow-up + urgency signal |
| **Session 4 (Jan 26)** | Framing the dual purpose of the session, then four-theme synthesis across ALL sessions | ~14 min (3 framing + 8 synthesis + 3 check) | Convergence + retrospective + deepening |

### The Opening Grammar

The pattern reveals a **grammar** — a predictable structure that shifts based on session position in the engagement:

```
Setup:      "What do you want?" → list everything → prioritize
Session 1:  "Here's what you said" → validate → "Which path?" → work
Session 2+: "What happened with X?" → report → extract learning → work
Final:      "Here's the whole arc" → synthesize → converge → close
```

**Key observations:**

1. **Memory weight decreases over time.** Session 1 opens with ~15 minutes of memory recall (reading back all 7 items). Session 2 opens with one focused question ("did you meet with Oseas?"). Session 3 opens lighter still. The coach front-loads memory in early sessions to build trust, then relies on the established thread.

2. **The opening question encodes the session type.** Session 1's "Do you confirm?" is a validation question. Session 2's "How did it go?" is an accountability question. Session 3's "How did it go... and we have two sessions left" adds urgency. Session 4's prepared synthesis is a consolidation move. Each opening signals to the coachee what kind of session this will be.

3. **Check-in depth varies.** Session 1 has minimal check-in (coach jumps to memory recall). Session 2 has an extended personal check-in (car accident) that models vulnerability. Session 3 has a brief check-in. Session 4 skips casual check-in entirely in favor of a structured framing. The check-in is not formulaic — it serves the session's needs.

4. **The coach arrives with a hypothesis.** By Session 2, Horacio arrives knowing what he wants to check (the commitment). By Session 4, he arrives with a prepared synthesis and a hypothesis about the root cause. The opening reveals the coach's pre-session preparation.

### What This Means for Doc A

The opening grammar should be documented as a **pattern language** — not a script, but a set of recognizable patterns:

| Opening Pattern | When to Use | Signal to Coachee |
|----------------|-------------|-------------------|
| **Full recall** | Session 1 (or after long break) | "I remember you. We're picking up where we left off." |
| **Commitment follow-up** | Any session with an open commitment | "I'm tracking what you said you'd do." |
| **Urgency framing** | When engagement has known endpoint approaching | "We have limited time. Let's use it well." |
| **Retrospective synthesis** | Final session (or major milestone) | "Let me show you the whole picture." |
| **Broad exploration** | When no prior context exists, or coachee signals a reset | "What's alive for you right now?" |

## Part 2: The Commitment Cycle

Commitments are the primary mechanism connecting sessions. They create the thread that makes coaching a "one long conversation" rather than a series of isolated events.

### Commitment Tracking Across All Sessions

Stretch: include concrete examples, not just concepts. | Wed Jan 8 (Oseas 1:1) | **Exceeded.** Ruy prepared proposal, met Oseas, received alignment, connected with Leonardo, wrote product vision doc. | Validated success, then challenged: "Was this luck or design?" Pushed toward systematization. |
| **2** | (a) Prepare document for Leonardo capturing learning process design. (b) Send to Oseas for feedback on stakeholder criteria. Stretch: include example, open to Oseas' input. | By Fri Jan 17 | **Re-sequenced.** Did NOT formalize PMF process. Instead wrote deeper v2 vision doc + roadmap + validation hypotheses. Explained: needed precondition first. | Tracked re-sequencing logic without judgment. Validated it as legitimate ("the precondition wasn't met"). Separated two levels: vision adjustment (done) vs. process formalization (still pending). |

(b) Consider how team receives Ruy's more visible leadership. | Before Session 4 (Jan 26) | **Deepened.** The reflection bore fruit — Session 4's frustration examples (Oseas bypassing him, diffuse requests) were direct products of this reflection. ### The Commitment Cycle Pattern

The cycle is not simply "commit → do → report." It has internal structure:

```
Commit (end of session N)
    ↓
Act (between sessions)
    ↓
Report (opening of session N+1)
    ↓
    ├── If completed: Extract → "Was it luck or design?" → Systematize → New commitment
    ├── If re-sequenced: Track logic → Validate adjustment → Check if original still pending
    ├── If not done: Non-judgmental inquiry → "What happened?" → Diagnose (avoidance vs. obstacle)
    └── If exceeded: Celebrate briefly → Challenge → Push to next level
```

### Critical Distinctions in Follow-Up

**1. Re-sequencing vs. Avoidance** (Session 3)

Ruy did not complete the Session 2 commitment (formalize PMF learning process). Instead, he worked on a prerequisite (v2 vision document). Horacio distinguished:

- **Valid re-sequencing:** "I discovered a precondition I hadn't seen" — the substitute action is logically upstream, the coachee can articulate why, and the original commitment is still acknowledged.
- **Strategic procrastination:** The coachee does adjacent work that feels productive but avoids the harder thing.
- **Outright avoidance:** "I didn't get to it" with no substitute action.

Horacio accepted the re-sequencing because all three signals of validity were present.

**2. "Hay que" to "Voy a" conversion** (Session 2)

When Ruy used impersonal language at commitment time ("hay que volver a algun artefacto"), Horacio caught it immediately:

> "Te propongo que transformemos el 'hay que' en 'voy a' o 'me comprometo a'."

This micro-skill is about converting organizational observation into personal commitment. The handbook describes commitment as asking "¿Lo harás?" and "¿Para cuándo?" — the praxis adds detecting hedging language patterns in real time.

**3. Commitment escalation** (Sessions 1→2→3→4)

The commitments escalated in type across the engagement:

| Session | Commitment Type | Level |
|---------|----------------|-------|
| 1 | Behavioral: do a specific task | Action |
| 2 | Operational: design a system | Process |
| 3 | Reflective: examine an identity pattern | Being |
| 4 | Declarative: accept a role + self-coaching question | Identity |

This escalation mirrors the goal hierarchy (Tracking → Management → Destination) and the BE→DO→HAVE model. The coaching process naturally deepens the level at which commitments operate.

### What the Handbook Says vs. What Practice Shows

| Handbook (Theory) | Practice (Observed) |
|-------------------|---------------------|
| Ask "¿Lo harías?" → "¿Lo harás?" → "¿Para cuándo?" → "¿Me avisas?" | Present in all 4 sessions, but adapted. Session 3 commitment is reflective, not behavioral — no "by when" for a mindset shift. |
| "If they're not ready for full action, ask what they ARE ready to do." | Not observed — Ruy was always ready for action. But the re-sequencing in Session 3 is related: the coachee found what he WAS ready to do (vision doc) before what he wasn't yet (process formalization). |
| Report back serves accountability + safety net + reflection | Confirmed. Session 2 opening is exactly this. The report back also serves as session architecture — it determines how Session 2+ begins. |
| Offer that changing their mind is OK — "but still contact you to discuss." | Not explicitly observed. Horacio's follow-up is framed as curiosity, not enforcement. |

## Part 3: Topic Threading — How Themes Carry Across Sessions

### The Theme Map

```
Session 0 (Setup):  7 aspirational items identified, 2 prioritized
                     │
Session 1:          Missing strategic conversations ←── emerged from priority #1
                     │                                   Yellow light: conceptual-vs-actionable
                     │
Session 2:          Learning process systematization ←── continuation of Session 1 theme
                     │                                   Sigma loss as learning catalyst
                     │                                   Product vision pivot
                     │
Session 3:          Theme graduation: strategic conversations → leadership identity
                     │  Surface theme declared "mostly unblocked"
                     │  Deeper theme emerged from side comment
                     │  Impostor syndrome (from Session 1) now has concrete content
                     │
Session 4:          Leadership identity deepened → role acceptance
                     │  Two concrete frustration examples
                     │  Formal declaration: "I accept, like a marriage"
                     │  Gift question for continuation
```

### Theme Graduation: The Central Pattern

The most important inter-session pattern observed: **theme graduation** — surface issues resolve, revealing deeper root causes.

**How it happened:**

1. **Sessions 1-2:** Ruy works on "missing strategic conversations" — a real problem but a surface symptom.
2. **Session 2-3 between sessions:** Ruy takes action (vision doc, Leonardo conversation). The surface problem gets substantially unblocked.
3. **Session 3:** With the surface issue handled, cognitive and emotional space opens. A "side comment" about undervaluing organizational work reveals the deeper pattern.
4. **Horacio's recognition:** "Nació como un comentario tuyo casi complementario... pero yo le veo una riqueza potencial interesante."
5. **Session 3-4:** The deeper theme (not owning the leadership role) becomes the primary thread.
6. **Session 4:** The deeper theme reaches resolution (role acceptance).

**The pattern in abstract:**

```
Surface problem → Work on it → Partial resolution → Space opens →
Deeper pattern becomes visible → Work on THAT → Identity-level resolution
```

This is not accidental. It is a natural consequence of:
- The coachee feeling safer (trust builds over sessions)
- The coachee feeling more accomplished (surface wins build confidence)
- The surface work removing cognitive load, making room for deeper reflection

### Vocabulary Continuity

Specific language carries across sessions and accumulates meaning:

| Term | First Appeared | How It Evolved |
|------|---------------|----------------|
| **"Víctima a protagonista"** | Session 1 (implicit — Ruy identifies complaint mode) | Session 3: Horacio names the transition explicitly using this Axialent vocabulary |
| **"Zona de stretch"** | Session 1 (Horacio's challenge: include concrete examples) | Implicitly embedded in subsequent commitments. The stretch escalates: from "add examples" to "design a system" to "examine your identity" |
| **"Impostor syndrome"** | Session 1 (Ruy self-labels) | Session 3: Gets connected to specific behavior (undervaluing organizational work). Session 4: Gets connected to role acceptance |
| **"Hay que" → "Voy a"** | Session 2 (Horacio catches hedging language) | Becomes an implicit standard — by Session 4, Ruy's commitments are naturally in first person |
| **"Precondición"** | Session 3 (Ruy explains why he re-sequenced) | Horacio validates this language — it becomes part of the shared vocabulary for tracking logical dependencies |
| **"Bola de billar" / "Carambola"** | Session 3 (Horacio's metaphor) | Carries into Session 4's four-theme synthesis — the metaphor explains WHY the root cause connects to multiple surface issues |

### What Carries and What Drops

**What carries forward:**
- Active commitments (tracked explicitly)
- Named themes (strategic conversations → leadership identity)
- Shared vocabulary (víctima/protagonista, zona de stretch)
- Yellow lights (flagged topics for future exploration)
- Named entities (Oseas, Leonardo, Mike — people referenced in coaching context)

**What drops:**
- Resolved tactical items (once Ruy met with Oseas, that specific task drops)
- Abandoned items (the 7 original aspirational items from setup — only 2-3 remained active by Session 3)
- Items explicitly deferred ("helping Shamil grow" — raised in Session 3, explicitly tabled)

**What gets transformed:**
- "Missing strategic conversations" → "learning process systematization" → "leadership identity" — the same underlying energy moves through three different framings as understanding deepens.
- "Conceptual-vs-actionable tendency" → The yellow light from Session 1 becomes less relevant as Ruy naturally becomes more concrete through the process. By Session 4, it's no longer mentioned — the pattern may have been a symptom of the deeper issue (not owning the role), and as the root was addressed, the symptom resolved.

### Where Practice Diverges from Theory

**1. The 8 steps are a scaffold, not a script.**

The handbook presents them sequentially. In practice:
- Comprensión and Contrato blend (Session 1: the topic emerges through exploration, and the contract is implicit)
- Resolución weight varies enormously (Session 1: light, one challenge. Session 2: heavy system design work)
- Some sessions skip or minimize steps (Session 3's cierre is rushed due to time)

**2. Contrato is almost always implicit.**

The handbook devotes significant space to negotiating product, process, and coaching objectives explicitly. In observed practice, the contract is emergent — Horacio follows the energy and then names what they're doing ("lo estoy entendiendo como un foco más puesto en..."). The formal three-objective contract structure was never observed.

**3. Role plays were absent.**

The handbook describes role plays as the primary resolution tool. Horacio never used role plays in Ruy's engagement. The resolution phase used:
- Challenge questions ("Was this luck or design?")
- Reframing ("frustration is a yellow light")
- Desdoblamiento (third-person self-observation)
- Direct questioning ("Do you accept this role?")
- Sharpening questions ("Who exactly? Any meeting or selective?")

This may be context-dependent — Ruy's issues were about organizational design and identity, not about difficult interpersonal conversations where role play would shine.

**4. Cierre varies dramatically.**

The handbook prescribes: learnings, extension, anchoring, feedback for coach, future coordination, appreciation. In practice:
- Session 1: Coachee-led closing (Horacio invites Ruy to summarize)
- Session 2: Brief mutual check-out
- Session 3: Rushed, abbreviated
- Session 4: Extended ritual with gift question (most closely matches handbook)

The closing only gets full treatment in the final session. Mid-engagement closings are efficient and forward-looking.

**5. Seguimiento is integrated, not separate.**

The handbook describes a post-session follow-up email. In practice, seguimiento is woven into the session itself — the closing always includes a forward reference that creates the thread for the next session. No evidence of formal follow-up emails between sessions.

**6. The Pre-Diagnostic Question is not in the handbook.**

Horacio's most powerful technique — asking the coachee to identify their own development areas BEFORE seeing diagnostic data — is a praxis innovation. The handbook describes diagnostic administration and feedback but not this specific sequence. Horacio considers it "lo más poderoso que yo he visto."

## Part 7: The Development Arc — Coaching as Architecture

### How the 4-Session Arc Demonstrates the Inter-Session Architecture

Reading across all 4 sessions as one "long conversation" reveals an arc with internal logic:

**Act 1 — Discovery (Session 1):**
- The surface problem is identified (missing strategic conversations)
- The coach demonstrates memory, builds trust, establishes the thread
- The coachee is in frustration mode — energy is available but unfocused
- First commitment creates the accountability thread

**Act 2 — Action (Session 2):**
- The commitment is fulfilled (and exceeded)
- Positive energy — reporting, building, designing
- The coach transforms the positive experience into generalizable learning
- The coachee shifts from complaint to protagonist mode
- Second commitment escalates: from "draft a proposal" to "design a system"

**Act 3 — Depth (Session 3):**
- Surface theme is declared substantially handled
- With surface resolved, deeper pattern becomes visible
- The "side comment" reveals the root cause (not owning leadership identity)
- The coach catches the emergent and deepens it
- Third commitment is reflective — identity level, not behavioral

**Act 4 — Resolution (Session 4):**
- Coach arrives with retrospective synthesis connecting all themes
- Root cause gets concrete expression through frustration examples
- Climactic moment: "I accept, like a marriage"
- Closing ritual transfers the coaching lens to the coachee (gift question)

### The Architecture's Internal Logic

```
                 Session 1          Session 2          Session 3          Session 4
                 ─────────          ─────────          ─────────          ─────────
Energy:          Frustration    →   Optimism       →   Vulnerability  →   Resolution
Topic level:     Surface        →   Tactical       →   Root cause     →   Identity
Commitment:      Behavioral     →   Operational    →   Reflective     →   Declarative
Coach role:      Navigator      →   Architect's    →   Depth          →   Synthesizer
                                    assistant          explorer
Opening:         Full recall    →   Commitment     →   Light          →   Retrospective
                                    follow-up          follow-up          synthesis
```

This is not prescriptive — not every coaching engagement will follow this arc. But it reveals the **natural tendency** of well-structured coaching: surface → depth → resolution.

### What This Means for AI Coach Design

1. **The AI Coach must support multiple session types**, not just "generic coaching session." The opening, the work, and the closing differ based on where the session sits in the arc.

2. **Commitment tracking is the primary connective tissue.** Without it, sessions become isolated events. The AI has a natural advantage here — perfect recall, proactive follow-up.

3. **Theme graduation is a feature, not a bug.** When topics evolve from surface to depth, that's progress. The AI must recognize this and support it, not force the coachee back to the original stated topic.

4. **The closing is as important as the opening.** Session 4 demonstrates that a well-designed closing (gift question, continuation path, acceptance moment) creates lasting value beyond the engagement.

5. **The inter-session architecture IS the coaching methodology.** Individual session technique matters, but the real methodology is in how sessions connect, how themes evolve, and how the "one long conversation" unfolds over time.
